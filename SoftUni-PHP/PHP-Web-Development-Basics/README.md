# SoftUni PHP Web Development Basics

Solutions for the SoftUni PHP Web Development Basics course: advanced syntax, HTTP and HTML forms, MySQL-backed apps,
OOP, sessions and authentication, routing, REST + AJAX, and the workshops that grow into a small MVC framework. Each
lecture folder has a `test_*.php` script.

## Run

Needs PHP 8.5 (and MySQL for the database lectures – load the folder's `schema.sql`).

```bash
cd 017-Exercise-Session-Handling-And-Authentication
php test_017_exercise_session_handling_and_authentication.php
php -S localhost:8000        # open http://localhost:8000
```
