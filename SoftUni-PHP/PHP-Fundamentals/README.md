# SoftUni PHP Fundamentals

Solutions for the SoftUni PHP Fundamentals course: console problems on syntax, arrays, functions, OOP basics,
associative arrays, text processing and regex, plus the HTML/CSS lectures and a small web project. Each lecture folder
has one `.php` file per problem and a `test_*.php` script that runs them against the expected output.

## Run

Needs PHP 8.5.

```bash
cd 008-Exercise-Arrays
php 001_train.php            # type the input, Enter
php test_008_exercise_arrays.php
```

Web lectures (HTML/CSS, the phonebook) run with the built-in server: `php -S localhost:8000` in the folder.
