# SoftUni C# Advanced

Solutions for the SoftUni C# Advanced course: stacks and queues, multidimensional arrays, sets and dictionaries, streams /
files / directories, functional programming, defining classes, generics, iterators and comparators. One console project
(`ExNNN`) per problem; every lecture has its own solution and tests, and [CS-Advanced.slnx](CS-Advanced.slnx) holds them
all.
