# SoftUni Data Structures Fundamentals with C#

Solutions for the SoftUni Data Structures Fundamentals with C# course: hand-written lists, stacks, queues, linked lists,
trees with BFS / DFS, heaps, priority queues and binary search trees. Each structure has an NUnit test project next to
it, all in [Data-Structures-Fundamentals.slnx](Data-Structures-Fundamentals.slnx).
