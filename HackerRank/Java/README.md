# HackerRank Java

My solutions to 55 HackerRank problems in Java, mostly from the
[Algorithms › Warmup and Implementation](https://www.hackerrank.com/domains/algorithms) tracks plus a few from the
[Java track](https://www.hackerrank.com/domains/java). Every solution in
[`src/main/java/com/cs/solutions`](src/main/java/com/cs/solutions) has a JUnit test with the same name in
[`src/test/java`](src/test/java).

Problems include Solve Me First, Plus Minus, Time Conversion, Climbing the Leaderboard, Extra Long Factorials, Non-Divisible
Subset, Queen's Attack II, The Grid Search, The Bomberman Game, Absolute Permutation, Bigger is Greater and The Time in
Words.

## Run the tests

```bash
./gradlew test
```
