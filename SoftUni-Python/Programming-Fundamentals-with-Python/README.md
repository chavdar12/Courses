Solutions for the SoftUni Programming Fundamentals with Python course: data types, lists, functions, objects and
classes, dictionaries, text processing, regular expressions, bitwise operations and mid / final exam preparation. One
`.py` file per problem.

Needs Python 3.14. Every lecture has a `test_*.py` that runs each solution with sample input.

```bash
python -m unittest -v
```
