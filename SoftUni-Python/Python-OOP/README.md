# SoftUni Python OOP

Solutions for the SoftUni Python OOP course: classes and objects, inheritance, encapsulation, static and class methods,
polymorphism and abstraction, SOLID, iterators and generators, decorators, unit testing, design patterns and two
workshops (custom list, hash table). Multi-file exercises are folders with a `project` package; each exercise has its
own `unittest` tests.
