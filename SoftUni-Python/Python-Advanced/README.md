# SoftUni Python Advanced

Solutions for the SoftUni Python Advanced course: stacks and queues, tuples and sets, multidimensional lists,
comprehensions, advanced functions, file handling, modules, error handling, two console game workshops and exam
preparation. One `.py` file per problem.

## Run

Needs Python 3.14. Every lecture has a `test_*.py` that runs each solution with sample input.

```bash
cd 006-Exercise-Multidimensional-Lists
python 001_diagonal_difference.py         # type the input, Enter
python -m unittest -v
```
