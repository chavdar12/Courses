# SoftUni Front-End Technologies Basics

Solutions for the SoftUni Front-End Technologies Basics course (QA track): HTML & CSS pages, async JavaScript, DOM,
single page apps and testing them with QUnit, Jasmine and Playwright. Every lecture folder is its own npm project
with a `npm test` script.

## Run

```bash
cd 019-Jasmine
npm install
npm test
```

The single page apps come with the SoftUni practice server in `server/` (port 3030). Start it, serve the app, then
run the Playwright tests:

```bash
cd 016-Exercise-JS-UI-testing
npm install
npx playwright install chromium
npm run server     # terminal 1 – http://localhost:3030
npm start          # terminal 2 – http://localhost:3001
npm test           # terminal 3
```
