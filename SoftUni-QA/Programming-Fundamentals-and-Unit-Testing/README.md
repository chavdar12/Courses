# SoftUni Programming Fundamentals and Unit Testing

Solutions for the SoftUni Programming Fundamentals and Unit Testing course (QA track), in C# on .NET 10. Every exercise
is a small console app with an NUnit test project next to it (`ExNNN/Tests`) that feeds the input through stdin and
checks the output. The unit-testing lectures have a `TestApp` class library and a `Tests` project that covers it.

## Run

```bash
dotnet run --project 008-Simple-Conditional-Statements/Ex005    # type the input, Enter
dotnet test 008-Simple-Conditional-Statements/Ex005/Tests
dotnet test 020-Unit-Testing-Methods/Tests
```

There is no root solution; CI collects every `.csproj` into a temporary one and runs `dotnet test` on it.
