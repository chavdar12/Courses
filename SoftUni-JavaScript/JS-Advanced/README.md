# SoftUni JS Advanced

Solutions for the SoftUni JS Advanced course: syntax and functions, arrays, objects and composition, DOM and events,
advanced functions, unit testing with Mocha + Chai, classes, prototypes and inheritance, and exam preparation. DOM
tasks are tested with jsdom.

## Run

Needs Node.js 24. Every lecture is its own npm project; tests use Mocha + Chai (and jsdom for the DOM tasks).

```bash
cd 010-Exercise-Dom-Manipulations-And-Events
npm install
npm test
```
