# SoftUni Programming Fundamentals with JavaScript

Solutions for the SoftUni Programming Fundamentals with JavaScript course: data types, arrays, functions, advanced
arrays, objects and classes, associative arrays and text processing. One `.js` file per problem.

## Run

Needs Node.js 24. Every lecture is its own npm project; solutions export a function that the Mocha + Chai tests call.

```bash
cd 014-Exercise-Associative-Arrays
npm install
npm test
```
