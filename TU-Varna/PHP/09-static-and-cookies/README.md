# 09 · Static members and cookies

| Path | What it does |
|------|--------------|
| `static-donations.php` | `Donation` class that totals all donations with `static` properties |
| `cookies/welcome.php` | Sets a `user` cookie and lists all cookies |
| `cookies/last.php` | Deletes the cookie |

```bash
php -S localhost:8000 -t 09-static-and-cookies   # open /cookies/welcome.php, then reload it
```
