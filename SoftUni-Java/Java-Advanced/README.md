# SoftUni Java Advanced

Solutions for the SoftUni Java Advanced course: stacks and queues, multidimensional arrays, sets and maps, streams /
files / directories, functional programming, defining classes, generics, iterators and comparators.

## Run

Needs JDK 25. Every lecture is its own Gradle project with a wrapper and JUnit tests.

```bash
cd 006-Exercise-Sets-And-Maps-Advanced
./gradlew build      # compiles and runs the tests
```

Or open the lecture folder in IntelliJ IDEA and run a class's `main`.
