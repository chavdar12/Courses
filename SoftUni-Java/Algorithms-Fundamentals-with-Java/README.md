# SoftUni Algorithms Fundamentals with Java

Solutions for the SoftUni Algorithms Fundamentals with Java course: recursion and backtracking, combinatorics,
searching, sorting and greedy algorithms, graph traversal and shortest paths, and dynamic programming.

## Run

Needs JDK 25. Every lecture is its own Gradle project with a wrapper and JUnit tests.

```bash
cd 006-Dynamic-Programming
./gradlew build      # compiles and runs the tests
```

Or open the lecture folder in IntelliJ IDEA and run a class's `main`.
