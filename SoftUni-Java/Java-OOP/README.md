# SoftUni Java OOP

Solutions for the SoftUni Java OOP course: working with abstraction, encapsulation, inheritance, interfaces,
polymorphism, SOLID, reflection and annotations, two workshops, unit testing, TDD, object communication and events,
design patterns and exception handling. Lectures with both parts are split into `Lab` and `Exercises`.

## Run

Needs JDK 25. Every lecture is its own Gradle project with a wrapper and JUnit tests.

```bash
cd 004-Interfaces-and-Abstraction
./gradlew build      # compiles and runs the tests
```

Or open the lecture folder in IntelliJ IDEA and run a class's `main`.
