# SoftUni Data Structures Advanced with Java

Solutions for the SoftUni Data Structures Advanced with Java course: 2-3 trees, AVL, red-black and AA trees, hash tables,
augmented data structures and the exam-prep tasks, each with JUnit tests.

## Run

Needs JDK 25. Every lecture is its own Gradle project with a wrapper and JUnit tests.

```bash
cd 004-Exercise-Red-Black-Trees-And-Aa-Trees
./gradlew build      # compiles and runs the tests
```

Or open the lecture folder in IntelliJ IDEA and run a class's `main`.
