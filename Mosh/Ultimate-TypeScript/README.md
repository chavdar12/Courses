# Ultimate TypeScript

Package scaffold of `@ultimate/vault`, a typed `localStorage` / `sessionStorage` utility with data structure and prefix
support, by [Ultimate Courses](https://ultimatecourses.com) ([upstream](https://github.com/ultimatecourses/vault)).

Only the package setup is here (`package.json`, `tsconfig.json`, the `src/index.ts` barrel). The implementation under
`src/lib/` was never added, so the package does not build and there is nothing to test yet.
